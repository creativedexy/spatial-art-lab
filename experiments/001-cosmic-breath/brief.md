# 001 — Cosmic breath

Status: ready to start. Source reference: [Dimitri Thouzery, Cosmic journey](https://www.instagram.com/p/C3aoMWPtiKD/). Study atmosphere and density without reproducing the artist's exact composition.

**Question:** Can a sparse monochrome field feel like a living volume?

**Output:** Three still variations, one 10-second motion sketch and a saved TouchDesigner source file. A seamless loop and audio reactivity are later extensions.

**Session A — 60–90 minutes:** Confirm TD build and save a new project. Make the smallest Noise TOP → Level TOP → Null TOP network. Adjust scale and contrast, then add slow movement. Save sparse, cloudy and fine-grained variants. Record which parameters created each look.

**Session B — 60–90 minutes:** Choose one variant. Explore gentle displacement; introduce one control at a time. Use a test signal and inspect how it changes the image. Save a moving preview. Keep enough darkness for the structure to read.

**Session C — 60–90 minutes:** Compare the first and latest versions at the same scale. Refine framing and speed, export a short capture, save the source and record three sentences about what worked. Use a preview size supported by the installed license and actual machine performance.

**AI help:** “Help me make a minimal monochrome moving field in TouchDesigner [build]. Explain each connection. I should be able to change density, contrast and speed manually. Suggest one addition at a time and tell me what result to expect.”

**Done:** Source reopens, three useful variants exist, movement is controlled, and we can explain what each main operator does. If displacement becomes a distraction, finish the simpler texture study first.
