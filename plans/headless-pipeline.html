Spatial art lab · plan · phase: Develop · 23 Sep 2026

One shot file, run headless, open any stage to adjust.

Every shot is described once, in shot.json. One command runs every stage without a window. Any stage can be opened in its own tool, changed by hand, and the change is written back to the same file, so the next headless run keeps it.

In plain English

Headless is for repeats: the same shot rebuilt after a change, ten variations overnight, a new plate through the same look. Adjusting is for taste: you open one stage, move sliders until it feels right, and the numbers land back in the shot file.

Ladybug is good at looks and at binding motion to sound, but it has no API and no documented project file, so it cannot be driven headless. So we took its ideas instead: Specimen Studio v2 has its layer structure, an effect layer, a finish stack and sound bindings, in a file we control and can run headless.
